# Bahaa Ahmed - QA/QC Portfolio

Static portfolio website. No build step is required.

## Local preview
Run a small local server from this folder:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages
For the cleanest personal URL, create a repository named `Bahaa-Elhamouly.github.io`, upload the contents of this folder to the repository root, then open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.

## Vercel
You can either import the GitHub repository into Vercel or use Vercel Drop with this folder/ZIP. Because this is a static HTML/CSS/JS site, no build command is required.
